## Proyectos incluidos

### Parcial 1

Proyecto académico desarrollado para aplicar conceptos de desarrollo web, lógica de programación y construcción de interfaces funcionales.

### Parcial 2

Proyecto académico enfocado en la organización del código, manejo de componentes y construcción de funcionalidades orientadas al usuario.

### Parcial 3

Proyecto académico orientado al desarrollo de una aplicación web con estructuras de datos, interfaces dinámicas y validación de funcionalidades.

### Proyecto Académico Frontend EcoMart

Aplicación frontend académica relacionada con una plataforma de comercio electrónico. Incluye construcción de interfaces, manejo de vistas y funcionalidades orientadas a la experiencia del usuario.

### Proyecto Académico HomeFix

Aplicación académica de servicios de cursos sobre ciberseguridas, desarrollada con enfoque en frontend, componentes reutilizables, flujo de usuario y organización del código.

## Cómo ejecutar los proyectos

Para ejecutar alguno de los proyectos, ingresa a la carpeta correspondiente y usa los siguientes comandos:

```bash
npm install
npm run dev
```

Luego abre en el navegador el enlace localhost generado por Vite.
